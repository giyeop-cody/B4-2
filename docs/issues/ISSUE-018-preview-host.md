# 이슈 #18: Vite가 Arena 미리보기 호스트를 403으로 차단

## 발생

개발 서버는 `0.0.0.0:4173`에서 실행됐지만 사용자 미리보기 주소는 HTTP 403을 반환했다.
Vite 로그는 임시 `.e2b.app` 호스트가 허용되지 않았다고 알려줬다.

## 원인

최신 Vite 개발 서버는 모르는 Host 요청을 기본 차단한다. 샌드박스 밖 브라우저는 localhost가 아니라 프록시된 임시 호스트로 접속한다.

## 선택

- 모든 호스트 허용: 간단하지만 범위가 너무 넓다.
- `.e2b.app` 하위만 허용: 미리보기는 되고 범위는 제한된다.

두 번째를 골라 `server.allowedHosts`에 `.e2b.app`을 추가했다. 이 설정은 개발 서버용이며 제품 빌드에는 서버를 포함하지 않는다.

## 재검사

미리보기 Host 헤더로 첫 화면을 요청해 HTTP 200을 확인했고, 제품 빌드도 통과했다.
