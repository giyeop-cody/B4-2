# 이슈 #14: Git 작성자 정보가 없어 커밋 실패

## 발생

`learning` 브랜치에서 첫 문서 커밋을 실행했지만 `Author identity unknown` 오류가 났다.

## 원인

새 작업 환경의 Git에 작성자 이름과 이메일이 설정되지 않았다. Git은 누가 만든 기록인지 커밋에 넣어야 하므로 커밋을 거절했다.

## 선택지

- 전역 설정: 다른 저장소에도 영향을 주어 범위가 너무 크다.
- 현재 저장소 설정: 이 과제 저장소에만 영향을 준다.

## 해결

기존 저장소 커밋에서 확인한 작성자 정보를 `git config --local`로 설정했다.

## 재검사

문서 커밋이 정상 생성되는지 확인한다.
