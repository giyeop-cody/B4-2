# 이슈 #12: 문서가 과제 원문과 최종 코드에 맞지 않음

## 발견한 차이

- 과제 원문은 80시간인데 README와 QUEST는 80분이었다.
- 현재는 인증이 있는데 README는 “인증 사용 안 함”이라고 했다.
- 실제 8개 라우트·11개 컴포넌트·3개 훅인데 6개·8개·2개라고 했다.
- React Router 7로 보안 갱신했지만 6이라고 적혀 있었다.
- 자동 LocalStorage 대체를 계속 권장해 원격 필수 조건과 어긋났다.
- 테스트 명령, 성능 보너스, 보호 라우트가 문서에 없었다.

## 해결 원칙

과거 시행착오를 현재 사실처럼 바꾸지 않는다. README는 최종 사용 설명으로 다시 쓰고,
LEARNING은 맨 위에 현재 상태를 추가한 뒤 잘못된 핵심 설명만 바로잡았다.

## 수정

- 학습 시간: 80시간
- 분야/과목: AI/SW 기초, 웹 기초와 프론트엔드
- 실행: 원격 모드와 명시적 로컬 학습 모드 분리
- 구조: 7 pages, 11 components, 3 hooks, context/lib
- 라우트: 로그인과 보호 프로필을 포함한 8개
- 테스트: unit 20, E2E 2, 원격 CRUD
- 인증/성능 보너스와 RLS 한계
- 공개된 토큰·세션 폐기 안내

## 재검사

문서 안의 `80분`, “인증 사용 안 함”, 자동 fallback 권장 문구를 검색하고 현재 상태와 충돌하는지 확인한다.
React Router 6 문구는 과거 트러블슈팅임을 LEARNING 첫 부분에서 분명히 구분했다.
