# 이슈 #16: 첫 브라우저 검사에서 Chromium 시스템 라이브러리 누락

## 발생

Playwright용 Chromium을 받은 뒤 E2E 테스트 2개가 모두 시작 직후 실패했다.
오류의 핵심은 `libnspr4.so: cannot open shared object file`이었다.

## 원인

브라우저 실행 파일은 설치됐지만, 이 Linux 작업 환경에 브라우저가 사용하는 시스템 라이브러리가 없었다.
테스트 코드나 React 앱이 실행되기 전의 환경 문제였다.

## 해결 선택

- 필요한 파일을 하나씩 추측해서 설치하지 않았다.
- Playwright가 권장하는 `npx playwright install-deps chromium`을 사용했다.

공식 설치 명령은 여러 패키지를 설치해 용량이 늘지만, 필요한 버전 조합을 추측하는 실수를 줄인다.
CI에서는 이 명령을 환경 준비 단계에 넣어야 한다.

## 재검사

같은 테스트를 줄이거나 바꾸지 않고 다시 실행했다.

- CRUD 화면 흐름: 통과 (등록 → 상세 → 수정 → 삭제)
- 필터·보호 라우트·404: 통과
- 결과: 2개 모두 통과

## 배운 점

테스트 실패 위치를 봐야 한다. 브라우저가 뜨기도 전에 실패했다면 앱 코드부터 고치는 것이 아니라 실행 환경을 먼저 확인한다.
